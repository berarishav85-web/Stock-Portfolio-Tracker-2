# Stock Portfolio Tracker

## Project Description

Stock Portfolio Tracker is a simple Python program that calculates the total investment value of stocks based on manually defined stock prices.

## Features

- Enter stock names
- Enter quantity of stocks
- Calculate investment for each stock
- Calculate total investment
- Save the result to a text file
